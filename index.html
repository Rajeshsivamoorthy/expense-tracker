Save to GitHub

Every change is saved to a data file in a GitHub repository, so any device you connect shows the same entries. If this device is already connected for the car tracker, the same connection is used and nothing more is needed.

One token limited to the data repository, with Contents set to read and write. Create it on GitHub: the name and permission are filled in. Choose "Only select repositories" and pick your data repository.
